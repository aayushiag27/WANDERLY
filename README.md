# Wanderly ✈️

Wanderly is a responsive travel discovery website designed to help users explore destinations, discover stays and experiences, and find travel inspiration through a clean and modern interface.

## 🌍 Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section with travel search filters
- Popular destinations section
- Travel statistics section
- Why Wanderly section
- Featured travel offers
- Testimonials section
- Newsletter subscription section
- Footer with useful links
- Hover effects and interactive UI elements
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
WANDERLY/
│
├── index.html
├── style.css
├── script.js
└── images/
```

## 🎨 Design

Wanderly focuses on a simple, modern, and travel-oriented design with:

- Clean layouts
- Rounded cards
- Image-based destination sections
- Interactive hover effects
- Responsive navigation
- User-friendly search interface

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/aayushiag27/WANDERLY.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile

The navigation changes to a hamburger menu on smaller screens for better usability.

## 🎯 Project Goal

The goal of Wanderly is to create a visually appealing and user-friendly travel discovery homepage using fundamental web development technologies while practicing HTML structure, CSS styling, responsive design, and JavaScript DOM manipulation.
